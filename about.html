About Peekbank

The Peekbank project aims to make developmental eye-tracking data more accessible for sharing and reuse. We do this by reducing the amount of preprocessing necessary to perform typical analyses and by storing data in a common, tidy format that allows for easy cross-dataset comparisons.

We release new dated versions periodically to facilitate reproducibility (see Releases), and support an API via the peekbankr R package, which lets users access the data in Peekbank without writing queries.

Peekbank is open source and under active development. If you encounter a problem, please file an issue in the GitHub Issues page of the appropriate repository. If you would like to contact us directly, email us at peekbank-dev@lists.stanford.edu.

About this site

The visualizations follow standard analysis conventions for looking-while-listening data (Fernald, Zangl, Portillo, & Marchman, 2008): proportion target looking among target-and-distractor looks; landing-time reaction times on distractor-initial trials; onset-contingent looking curves. Trials excluded by the contributing labs are included by default (Peekbank archives all contributed data), and can be filtered with the “Excluded trials” toggle. Everything is computed in your browser from compact extracts of the current release; the full data live on Redivis.

Built with Quarto and Observable; source at peekbank/peekbank-datapage.
